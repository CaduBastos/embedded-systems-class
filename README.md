🐧 Embedded systems coursework
========================

This repository is dedicated to **Embedded Systems studies** and contains source code
developed as part of a **university-level Embedded Systems course** within an
Electrical Engineering program.

It serves as an academic and technical record of my practical experience with
low-level software development, Linux-based embedded environments, and system-level
programming concepts. This repository is part of my **professional GitHub portfolio**
and reflects my foundation in embedded software engineering.

## Technical Scope

The repository includes examples and exercises covering:

- **Shell scripting** for system automation and embedded workflows  
- **Makefiles** for building and managing embedded software projects  
- **Debugging techniques** using `printf` tracing and **GDB**  
- **Linux kernel modules** development  
- **C source files interfacing with Assembly routines**

## Purpose

- Academic learning and technical skill development  
- Hands-on practice with embedded and low-level programming  
- Reference material for embedded Linux and system programming concepts  

## Notes

- Code prioritizes clarity and learning over production-level optimization  
- Implementations may evolve as concepts are refined  
- Repository content reflects coursework requirements and experimentation
